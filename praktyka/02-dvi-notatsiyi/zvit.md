Програму квадрата з першої роботи переведено з блоків у Python. Код збережено у [kvadrat.py](kvadrat.py). Параметри залишилися ті самі: 4 повторення, рух уперед 2 с на швидкості 20%, поворот за гіроскопом на 90°.

## Відповідність блоків і коду

| Блок | Код у Python |
|---|---|
| Початок програми | Команди після імпортів і налаштування моторів та датчика |
| Задати `data = 90` | `data = 90` |
| Записати початковий кут гіроскопа | `rotation = gyro.angle` |
| Повторити 4 рази | `for _ in range(4):` |
| Їхати вперед 2 с, обидва мотори на 20% | `tank.on_for_seconds(SpeedPercent(20), SpeedPercent(20), 2)` |
| Повторювати до `rotation >= data` | `while rotation < data:` |
| Мотор A на 3% | `motor_a.on(SpeedPercent(3))` |
| Мотор B на −3% | `motor_b.on(SpeedPercent(-3))` |
| Оновити кут під час повороту | `rotation = gyro.angle` |
| Вивести кут | `print(rotation)` |
| Збільшити цільовий кут на 90° | `data = data + 90` |
| Зупинити мотор A з гальмуванням | `motor_a.off(brake=True)` |
| Зупинити мотор B з гальмуванням | `motor_b.off(brake=True)` |

## Коротке пояснення

Робот їде вперед, а потім повертається на місці: мотор A працює на 3%, мотор B — на −3%. Поворот триває, поки показ гіроскопа менший за заданий кут. Цільові кути — 90°, 180°, 270° і 360°. Після 4 повторень обидва мотори зупиняються.

Блок «повторювати до» задає умову завершення, а `while` — умову продовження. Тому `rotation >= data` у блоках відповідає `rotation < data` у циклі Python.

Перед запуском потрібно скинути симуляцію, щоб початковий кут був 0°. Гіроскоп підключено до порту 3, мотори — до A і B.
